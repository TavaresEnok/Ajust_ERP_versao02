# Repositório oficial do Ajust ERP

O único repositório de desenvolvimento e publicação deste projeto é:

https://github.com/TavaresEnok/Ajust_ERP_versao02

O remoto `origin` deve usar `git@github.com:TavaresEnok/Ajust_ERP_versao02.git` para receber e enviar alterações. A configuração local define `origin` como destino padrão de envio e mantém o nome da branch atual no envio.

`Ajust_ERP_versao01` é o repositório anterior e não deve receber novas atualizações deste projeto.

As pastas locais `Ajust_ERP` e `Ajust_ERP-pre-redesign` são worktrees do mesmo Git e compartilham a configuração de remotos. Elas não representam dois destinos no GitHub.

A definição do repositório oficial não envia automaticamente arquivos locais modificados ou ainda sem commit. Antes de publicar alterações, revisar o conteúdo, registrar os commits e enviá-los ao `origin`.

Definição registrada em 24/10/2026.
